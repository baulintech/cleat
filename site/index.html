Lock what your AI agent skills depend on.

Many agent skills tell your coding agent to read a page, download a file or run a script hosted somewhere else. You review the skill once, but what those links serve can change tomorrow. Cleat records what every link served when you reviewed it, and fails your build if that changes.

The problem

You approve a skill's files, not what its links serve next week.

We measured how often popular agent skills reach for outside content, and how often those references are pinned to something that can't change.

355

popular agent skills studied, from 20 widely used repositories

36%+

explicitly tell the agent to read, download or run something hosted elsewhere

13 / 4,273

outside links were pinned to a fixed version or hash

We found no hidden malicious content. Most links point to the publishers' own sites. The risk is exposure: a link that changes owner, or content, is trusted automatically. Figures from Ampaw (2026).

How it works

Three commands. No dependencies. It never runs the skill.

01 · scan

See what it reaches for

Lists every outside reference, including ones hidden in comments, base64 or invisible Unicode, and labels how each is used: run, download, instruction or mention.

02 · lock

Fingerprint what you reviewed

Fetches each link read-only and records SHA-256 fingerprints of the skill's files and the remote content in a lockfile you commit.

03 · verify

Catch the change

Compares against the lock. New links, changed content and edited files are reported, and the command exits non-zero so CI stops.

$ node cleat.mjs lock doc-helper
Locked 2 link(s) and 0 package(s)

# later, the skill is updated with one new line…
$ node cleat.mjs verify doc-helper
DRIFT DETECTED. 2 change(s) need review before you keep using this skill.

CRITICAL new-reference  url:https://get.doc-helper.dev/install.sh
      - New link that was not there when the skill was locked (execute).

MEDIUM   skill-files-changed  skill
      - The skill's own files changed since it was locked (1 edited, 0 added, 0 removed).

exit code 1

Real Cleat 0.1.4 output, lightly trimmed. The install address is made up for the demo.

Scope

What it does, and what it doesn't.

Does

  • Inventory outside links, scripts and package installs in a skill
  • Find references hidden in HTML comments, base64 and invisible characters
  • Fetch read-only through a guarded fetcher that blocks private and local addresses
  • Flag unpinned packages and red-flag patterns such as pipe-to-shell installs
  • Run anywhere with Node.js 18+, as an agent skill or a CI step

Doesn't

  • Run the skill, so behaviour that only appears at run time is out of scope
  • Guarantee safety: a server can show Cleat one thing and your agent another
  • Catch links built at run time or hidden in obfuscated code
  • Judge intent: rules catch known shapes, not every plain-English instruction
  • Replace a human review: it protects what you approved when you locked it
Research

Built from a published study.

Cleat was the instrument for a study of 355 popular agent skills. The report sets out the method, a validation of the tool's labels against random samples, and the limits. It's open access under CC BY 4.0, and the data and scripts are in the repository.
