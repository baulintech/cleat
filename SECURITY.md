# Security policy

Cleat reads content chosen by people who may be hostile, so bugs in it matter.

Please report security problems privately to **hello@baulin.co.uk**, not in a
public issue. Include what you found, how to reproduce it, and the version.
You will get a reply within a week.

Especially welcome:

- ways to make the fetcher reach a private, local or metadata address
- ways to make a scan hang, crash or use unbounded memory
- text in a scanned skill or remote page that changes what the report says
- hidden references Cleat fails to find
